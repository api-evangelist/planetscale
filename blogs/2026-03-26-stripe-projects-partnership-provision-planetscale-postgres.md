We're excited to announce that PlanetScale is participating as a co-design and launch partner for Stripe Projects, a new developer preview from Stripe that centralizes dev tool provisioning and billing in one place. What is Stripe Projects? Stripe Projects is a new way for developers and coding agents to discover, provision, and pay for developer tools all from the Stripe CLI.
