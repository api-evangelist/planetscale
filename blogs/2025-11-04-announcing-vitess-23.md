We’re excited to release Vitess 23.0.0 — the latest major version of Vitess — bringing new defaults, better operational tooling, and refined metrics. This release builds on the strong foundation of version 22 and is designed to make deployment and observability smoother, while continuing to scale MySQL workloads horizontally with confidence. Why this release matters For production users of Vitess, this release is meaningful in several ways: Upgrading defaults: Moving to MySQL 8.4 as default future-proofs deployments and signals forward compatibility.
